# Models

This folder is reserved for serialized final models and preprocessing objects when permitted by repository size and course policy.

The final academic conclusion is based on leave-one-well-out predictions, not on the performance of a model refitted to all data. If a full-data model is serialized for demonstration, label it clearly as a deployment candidate that has not been externally validated.

Required accompanying files:

- model configuration
- feature list and order
- preprocessing specification
- software versions
- training data hash
- model card
- intended and prohibited uses

## Included demonstration artifact

`final_logistic_vsh_phit.joblib` is a full-data refit for demonstration and reproducibility only. It is not the basis of the leave-one-well-out performance estimate and has not been externally validated.
