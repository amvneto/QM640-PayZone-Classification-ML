# Anonymization and Public Data Use

## Statement

The empirical dataset is fully anonymized before public analysis. It contains no company, client, field, platform, geographic, coordinate, original well-name, or proprietary service identifier. Anonymous W01-W06 codes are retained only because well-level grouping is necessary for leakage-resistant validation.

Because the repository contains only anonymized data and derived academic materials, a separate client-release approval document is not required for this capstone submission.

## Publication boundary

Allowed: anonymized tables, processed copies, code, derived figures, model outputs, data dictionaries, reports, and presentations.

Not allowed: original reports, email correspondence, approval records, maps, coordinates, identifying screenshots, original filenames revealing the asset, or proprietary documents.

## Pre-upload scan

Search text, file names, document metadata, slide notes, and image headers for any prohibited identifier before committing.
