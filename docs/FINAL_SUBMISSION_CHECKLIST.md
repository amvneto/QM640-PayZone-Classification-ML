# Final Report Submission Checklist

- [ ] Submit PDF only to the course portal.
- [ ] Main report is no more than 20 pages.
- [ ] Appendices are no more than 5 additional pages.
- [ ] Title page and page numbering follow the final-report template.
- [ ] All figures and tables are labeled and referenced in the text.
- [ ] All four research questions are answered with final results.
- [ ] Sample-size calculations are included for each RQ.
- [ ] At least 10 relevant references are included in APA 7 format.
- [ ] GitHub link is correct and public.
- [ ] Repository contains the anonymized data, dictionary, documentation, code/notebooks, results, and model card.
- [ ] No company, client, field, platform, location, coordinate, or original well name appears.
- [ ] PDF metadata and embedded images have been checked.
- [ ] Similarity/plagiarism check has been run before submission; revise any uncited or overly similar text.
- [ ] Mentor feedback has been incorporated.
